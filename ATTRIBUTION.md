This project selects 13 supported symbol folders and 18 unsupported-character
folders, removes exact duplicates, assigns explicit Unicode labels, groups and
splits source pages, and derives normalized/augmented training inputs. Original
selected PNG bytes are retained unchanged. These processing changes and model
training are project work; the dataset contributors do not endorse this project.

The supplementary scribbles generated by this project are synthetic and are
reported separately from human handwriting. No font-generated positives or
application submissions are used for training.

## Software and pretrained model

The recognizer uses torchvision MobileNetV3-Small initialized with `MobileNet_V3_Small_Weights.IMAGENET1K_V1` (ImageNet-1K pretrained weights), then fine-tuned on the attributed Tamil corpus. The resulting ONNX contains the complete fine-tuned network, not a LoRA adapter. The original dataset, ImageNet images and original pretrained checkpoint are not included in this inference package.

Inference uses ONNX Runtime CPU, Pillow, NumPy, FastAPI/Uvicorn and the other pinned packages in [server/requirements.lock.txt](server/requirements.lock.txt). Copied upstream license/notice texts and package metadata are in [server/licenses](server/licenses/README.md). The drawing component and host glue are project code; this handoff does not invent or change their owner's license.
